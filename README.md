# Exercício 36 - Ordenação de Vetor

## Descrição

Programa desenvolvido em Java que lê 20 números inteiros, armazena os valores em um vetor e os organiza em ordem crescente. Ao final, exibe os números ordenados na tela.

## Tecnologias utilizadas

- Java
- Apache NetBeans IDE
- Maven

## Entrada

O programa solicita ao usuário 5 números inteiros.

## Saída

Exibe os 5 números armazenados no vetor em ordem crescente.
